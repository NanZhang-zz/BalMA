# BalMA
Official PyTorch implementation for Information Density-Balanced Multiscale Alignment for Remote Sensing Image-Text Retrieval.

## Code Availability
Code will be released upon paper acceptance.

## Data Availability
The original RS images and captions are available at https://github.com/arampacha/CLIP-rsicd.


This project builds upon the excellent work of the open-source community. We would like to thank the authors and developers of the following repositories for their valuable contributions:
GaLR: https://github.com/xiaoyuan1996/GaLR
LAPS: https://github.com/CrossmodalGroup/LAPS
